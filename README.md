# STUN-FI Skins

A Next.js ordering portal for precision-cut vinyl wraps for laptops, phones, and controllers.

## Features

- Device selection for laptop, phone, and controller
- Coverage selection for laptop wraps
- Finish pricing for Standard and Shiny Stones Sparkle
- Live total calculation with bundled pricing rules
- Custom text and design upload support
- WhatsApp order text generation
- Digital receipt download

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
